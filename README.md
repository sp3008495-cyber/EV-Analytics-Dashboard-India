# EV-Analytics-Dashboard-India
Interactive Tableau dashboard analyzing India's EV sales, charging infrastructure and manufacturer trends (2014-2024)
## 🔍 Overview
India is rapidly transitioning towards sustainable transportation through EV adoption. This project builds an interactive Tableau dashboard that transforms raw, scattered EV data into meaningful visual insights for policymakers, businesses, researchers, and the public.

## 🎯 Objectives
- Build an interactive Tableau dashboard using Electric Vehicle datasets
- Analyse EV sales trends across different years
- Compare state-wise EV sales and charging infrastructure
- Evaluate manufacturer performance and market share
- Analyse vehicle category and vehicle class-wise sales
- Provide interactive filters for dynamic exploration

## 📊 Dataset
Publicly available EV datasets covering **2014–2024**, including State-wise EV Sales, Manufacturers, Vehicle Categories/Classes, EV Penetration, and Charging Infrastructure (Fast & Slow chargers).

## 🖥️ Dashboard Features
- **KPI Cards** — Total EV Sales, Total States Covered, Average EV Penetration, Total Charging Stations
- **Interactive Maps** — State-wise EV Sales Map, Charging Stations Map
- **Trend Analysis** — Year-wise EV Sales Trend
- **Comparative Charts** — Vehicle Category/Class-wise Sales, Top 10 Manufacturers, State-wise Charging Stations
- **Filters** — Year, State, Vehicle Category, Vehicle Class, Manufacturer
